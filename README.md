# And Player – музыкальный плеер для Android.

##  Спецификация

Основные функции:
1. Главный экран: Отображение списка аудиозаписей, доступных на устройстве. Для каждой записи необходимо показать название, исполнителя (если доступен) и продолжительность.
2. Получение аудиофайлов: Используйте ContentResolver и системный ContentProvider (MediaStore) для получения списка музыки. Обработайте отсутствие разрешений и ситуацию, когда на устройстве нет аудиофайлов.
3. Воспроизведение музыки: Реализуйте воспроизведение, паузу, переключение между треками и перемотку на выбранную позицию.
4. Фоновое воспроизведение: Музыка должна продолжать играть при сворачивании приложения и блокировке экрана. Для этого необходимо использовать Foreground Service с типом mediaPlayback. Разберитесь с жизненным циклом сервиса и корректным освобождением ресурсов.
5. Управление через уведомление: При воспроизведении музыки должно отображаться системное медиауведомление с возможностью поставить трек на паузу, продолжить воспроизведение и переключить трек. Управление должно работать без открытия приложения.
6. BroadcastReceiver: Реализуйте реакцию на отключение проводных или Bluetooth-наушников. Когда аудиовывод переключается на динамик устройства, воспроизведение должно автоматически останавливаться на паузу. Используйте BroadcastReceiver и событие ACTION_AUDIO_BECOMING_NOISY.
7. Сохранение состояния: После повторного открытия приложения должна сохраняться информация о последнем прослушиваемом треке и его позиции.
8. Избранное: Пользователь может добавлять треки в избранное и просматривать их на отдельном экране.

Дополнительные задачи:
1. Добавить поиск по названию трека и исполнителю.
2. Реализовать очередь воспроизведения и перемешивание треков.
3. Добавить возможность повторять один трек или весь плейлист.
4. Реализовать реакцию на изменение медиатеки устройства, используя ContentObserver.
5. Добавить поддержку светлой и темной тем.

Технологический стек:
1. Язык: Kotlin.
2. UI: Jetpack Compose, Material 3.
3. Архитектура: MVVM.
4. Воспроизведение: Media3 ExoPlayer, MediaSession, MediaController.
5. Фоновые операции: Foreground Service (MediaSessionService).
6. Системные события: BroadcastReceiver.
7. Доступ к медиатеке: ContentResolver, MediaStore, Cursor.
8. Хранение данных: Room или DataStore.
9. Асинхронность: Kotlin Coroutines, Flow.

Критерии готовности:
- Музыка продолжает воспроизводиться после сворачивания приложения.
- Воспроизведением можно управлять из системного уведомления и с экрана блокировки.
- При отключении наушников воспроизведение останавливается на паузу.
- После возвращения в приложение пользователь видит актуальное состояние плеера.
- После завершения воспроизведения ресурсы сервиса корректно освобождаются.
- Приложение корректно обрабатывает отсутствие доступа к аудиофайлам.
